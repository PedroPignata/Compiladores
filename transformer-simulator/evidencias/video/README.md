# Vídeo de demonstração

`demonstracao-transformer.mp4` apresenta, em 22 segundos, a entrada, as etapas
intermediárias, o mapa de atenção, a geração progressiva e o resultado final.
O vídeo possui resolução 1280 × 720, codec H.264 e não contém áudio.

Para recriá-lo depois de atualizar as capturas:

```bash
pip install -r requirements-dev.txt
python scripts/generate_demo_video.py
```
